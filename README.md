# إدارتك المالية - تطبيق ويب تقدمي (PWA) للإيرادات والمصروفات

تطبيق لإدارة الإيرادات والمصروفات الشخصية مصمم بنفس الواجهة والألوان والخطوط الموضحة، ويعمل كتطبيق ويب تقدمي (PWA) على الهواتف (Android و iOS) والكمبيوتر.

---

## 🌟 مميزات التطبيق

1. **تصميم متطابق 100% مع الصور**:
   - خط **Cairo** المريح والمطابق للأصل.
   - شريط التنقل العلوي: **المعاملات** | **التقارير** | **التحليل**.
   - بطاقة الملخص المالي مع النصائح الذكية التلقائية.
   - بطاقة التقارير الشهرية مع الرسم الدائري لتوزيع المصروفات (Donut Chart).
   - نافذة إضافة المعاملات السفلية (Bottom Sheet) مع الحقول المحددة (Outlined Inputs).
   - **إدارة كاملة للفئات**: إمكانية إضافة، وتعديل أسماء، وحذف فئات المصروفات والإيرادات مع تحديث تلقائي لكافة المعاملات المسجلة.
   - زر الإضافة العائم الأزرق (+) في أسفل الشاشة.
   - العبارة السفلية: **تم تطويره بواسطة أبوحمزة**.

2. **الاحتفاظ بالبيانات والخصوصية الكاملة (على جهازك فقط)**:
   - **بدون أي بيانات افتراضية**: التطبيق يبدأ بقاعدة بيانات نظيفة تماماً (0.00 ج.م).
   - البيانات تُحفظ محلياً على جهاز المستخدم حصراً (`LocalStorage`).
   - لا يتم إرسال أي بيان إلى أي خادم خارجي نهائياً.
   - إمكانية **تصدير نسخة احتياطية (JSON)** وحفظها في التنزيلات.
   - إمكانية **استعادة النسخة الاحتياطية** في أي وقت بضغطة زر.
   - إمكانية **تصدير ملف إكسل (CSV)** للمعاملات باللغة العربية.

3. **تقنية PWA (تطبيق الهاتف)**:
   - يعمل دون اتصال بالإنترنت بالكامل (Offline) عبر `Service Worker`.
   - يمكن تثبيته كأيقونة تطبيق على الشاشة الرئيسية للهاتف (Android / iPhone) أو سطح المكتب.

---

## 📱 كيفية تثبيت التطبيق على الهاتف

### على هواتف أندرويد (Google Chrome):
1. افتح رابط التطبيق في متصفح Chrome.
2. ستظهر لك رسالة تثبيت تلقائية أو اضغط على القائمة (⋮) ثم اختر **"إضافة إلى الشاشة الرئيسية"** أو **"تثبيت التطبيق"**.
3. سيظهر التطبيق على شاشة هاتفك مثل أي تطبيق مثبت ويعمل حتى لو انقطع الإنترنت.

### على هواتف آيفون (Safari):
1. افتح رابط التطبيق في متصفح Safari.
2. اضغط على زر المشاركة (مربع بسهم لأعلى).
3. مرر لأسفل واختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.

---

## 💻 التشغيل محلياً على جهاز الكمبيوتر

يمكنك فتح ملف `index.html` مباشرة في أي متصفح، أو تشغيل خادم محلي:
```bash
python -m http.server 8000
```
ثم فتح المتصفح على الرابط:
`http://localhost:8000`
